## 这是什么

一个本机跑的微信监控中台：

1. **轮询新消息**：定期读取本地解密后的数据库（配合 `wechat-decrypt` 使用）
2. **关键词/规则告警**：命中重要规则的消息置顶提醒
3. **LLM 判分**：让模型给消息打分，只推值得看的
4. **语音转写**：把语音消息转成文字一并归档
5. **定时日报**：每天固定时间出一份汇总
6. **网页看板**：浏览器看关注列表、消息流、告警

## 架构

```
微信本地库 ──(wechat-decrypt)──> 解密库 ──> 监控轮询 ──> 规则过滤 ──> LLM 判分 ──> 看板/告警
                                                    └──> 语音转写 ──> 归档
```

## 快速开始

1. 先用 [`wechat-decrypt`](https://github.com/enhaopang-dot/wechat-decrypt) 把本地库解开
2. 复制 `config.example.json` 为 `config.json`，填你自己的账号与路径
3. 启动：

```bash
python ops_center.py
# 浏览器打开 http://127.0.0.1:5690
```

## 配置项

| 配置 | 说明 |
|---|---|
| `monitor_runtime` | 解密后的运行时目录 |
| `accounts` | 要监控的账号及备注 |
| `poll_seconds` | 轮询间隔 |
| `quiet_seconds` | 静默判定时长 |
| `daily_time` | 每日汇总时间 |
| `llm` | 判分用的模型端点 |

## 目录

```
├── ops_center.py        主程序：轮询、规则、看板、告警
├── mp_scan.py           公众号扫描
├── voice_fetch.py       语音拉取
├── voice_transcribe.py  语音转写
├── report_period.py     周期报告

├── static/index.html    网页看板

```

## 设计取舍

- **本机跑**：消息不出你电脑，模型端点可指向本地或你自己信任的服务
- **规则优先、模型兜底**：便宜的规则先过滤，贵的模型只判剩下的
- **全量留痕**：每条告警都能追到原始消息
